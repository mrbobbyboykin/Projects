## One-time setup

1. Push this folder to the `Projects` repo on GitHub (`main` branch).
2. In the repo on GitHub: **Settings → Pages → Source → GitHub Actions**.
3. After push, confirm **Deploy demo sites to GitHub Pages** succeeds in the **Actions** tab.
